# Asset policy

The UI uses CSS panels, Lucide React icons and a code-native product icon.
There are no stock photographs, generated raster assets, image-search dependencies
or runtime image-service requests. The user requested no image-credit spending.

Snapshot/recording features draw a labelled geometric test frame directly onto a
browser canvas. Those are user-triggered local exports, not purchased/generated
UI images or actual camera footage. Browser QA uses DOM assertions; screenshot
capture is not part of the test suite.
